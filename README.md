# Изгиб Питона

"Изгиб Питона" - учебный проект по предмету "Основы разработки на языке Python" (онлайн-магистратура НИЯУ МИФИ и Яндекс.Практикума).
Игра представляет собой черное поле 640×480 и клетки 20 пикселей. Змейка собирает яблоки и растёт, игра идёт до тех пор, пока не закрыть окно.

## Управление

- Поворот выполняется стрелками. Развернуться на 180° нельзя.
- При "наезде" на край поля змейка выходит с противоположной стороны.
- Каждое съеденное яблоко - плюс один сегмент к змейке.
- Если змейка укусила себя, то происходит сброс прогресса.

## Запуск

Для запуска игры нужен Python 3 с pygame. Устанавливать игру лучше в виртуальное окружение:

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
python the_snake.py
```

Для Python 3.14 и новее requirements.txt устанавливает pygame-ce, для более старых
версий pygame. Запуск игры проверен на Python 3.14.4 и pygame-ce 2.5.8.
